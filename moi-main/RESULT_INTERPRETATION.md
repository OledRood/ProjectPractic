# Интерпретация результатов analyze_video_for_backend()

## Структура результата

```json
{
  "status": "ok",
  "exercise": "pushup",
  "confidence": 98.5,
  "technique_issues": ["Увеличьте сгиб локтя до 80°"],
  "metrics": {
    "elbow_angle": 42.55,
    "torso_angle": 135.55,
    "knee_angle": 167.28
  }
}
```

## 1. Поле `status`

- **"ok"** — анализ выполнен успешно
- **"error"** — произошла ошибка (видео не найдено, недостаточно данных и т.д.)

---

## 2. Поле `exercise`

- **"pushup"** — отжимание от пола
- **"pullup"** — подтягивание на перекладине
- **"unknown"** — не удалось определить

### Как это работает:
1. BiLSTM модель анализирует последовательность поз на видео
2. Выбирается класс, который появляется в > 50% кадров
3. `confidence` показывает уверенность в этом решении

---

## 3. Поле `confidence`

Процент (0-100), насколько модель уверена в определении упражнения.

### Интерпретация:
| Confidence | Вывод |
|-----------|-------|
| ≥ 95% | Очень высокая уверенность ✅ |
| 80-95% | Хорошая уверенность ✅ |
| 60-80% | Средняя уверенность ⚠️ |
| < 60% | Низкая уверенность ❌ (подозрительно) |

### Когда может быть низкая уверенность:
- Видео размытое или низкого качества
- Человек не полностью в кадре
- Упражнение выполняется нестандартно
- Видео очень короткое (< 30 кадров)

---

## 4. Поле `technique_issues`

Список проблем с техникой выполнения.

### Для PUSHUP:

#### ✅ Хорошая техника (пусто):
```python
"technique_issues": []
```

#### ❌ Проблемы техники:
```python
"technique_issues": [
    "Локоть недостаточно согнут: 42° < 80°",
    "Спина наклонена: 135° (должна быть ~90°)",
    "Ноги согнуты: 120° (должны быть прямыми)"
]
```

### Для PULLUP:

#### ✅ Хорошая техника:
```python
"technique_issues": []
```

#### ❌ Проблемы техники:
```python
"technique_issues": [
    "Локоть не согнут достаточно: 75° < 90°",
    "Плечи ниже локтей (нужно подтягиваться выше)",
    "Корпус наклонен: 120° (должен быть вертикален)"
]
```

---

## 5. Поле `metrics`

Измеренные углы на основе позы человека.

### PUSHUP метрики:

```python
{
    "elbow_angle": 123.98,        # угол локтя (градусы)
    "torso_angle": 78.28,         # угол туловища
    "knee_angle": 167.28,         # угол коленей
}
```

**Норма для хорошей техники:**

| Метрика | Норма | Описание |
|---------|-------|---------|
| `elbow_angle` | **80-160°** | Локоть согнут (зависит от фазы) |
| `torso_angle` | **85-95°** | Спина параллельна полу |
| `knee_angle` | **165-180°** | Ноги прямые |

**Примеры результатов:**

| Scenario | elbow_angle | torso_angle | knee_angle | Статус |
|----------|-------------|------------|-----------|--------|
| Идеальная техника | 120° | 90° | 170° | ✅ OK |
| Локоть не согнут | **45°** | 90° | 170° | ❌ Issue |
| Спина наклонена | 120° | **130°** | 170° | ❌ Issue |
| Ноги согнуты | 120° | 90° | **140°** | ❌ Issue |

### PULLUP метрики:

```python
{
    "elbow_angle": 95.50,         # угол локтя
    "torso_angle": 88.35,         # угол туловища
    "knee_angle": 175.22,         # угол коленей
    "shoulders_high": True,       # плечи выше локтей?
}
```

**Норма для хорошей техники:**

| Метрика | Норма | Описание |
|---------|-------|---------|
| `elbow_angle` | **90-180°** | Локоть согнут (в верхней точке ≈ 90°) |
| `torso_angle` | **85-95°** | Корпус вертикален |
| `knee_angle` | **165-180°** | Ноги прямые |
| `shoulders_high` | **True** | Плечи должны быть выше локтей |

## Как проверить результат вручную?

### 1. Посмотреть видео со скелетом:
```bash
# После анализа видео, в output_videos/ появится видео со скелетом
open /Users/nikko/Downloads/moi-main/project_root/data/output_videos/video1_skeleton.mp4
```

На видео должны быть:
- 🟢 Зелёные линии — линии скелета
- 🟢 Зелёные точки — суставы (плечи, локти, запястья, бёдра, колени, лодыжки)
- 🟨 Жёлтый четырёхугольник — туловище

### 2. Проверить на нескольких видео:
```bash
python src/test_backend_api.py --video data/dataset/video/pushups/video1.mp4
python src/test_backend_api.py --video data/dataset/video/pushups/video2.mp4
python src/test_backend_api.py --video data/dataset/video/pullups/video5.mp4
```

Сравнить результаты и убедиться, что разные видео дают разные результаты.

### 3. Если что-то подозрительно:
- Проверить, что видео-файл существует и содержит видео с человеком
- Убедиться, что модели загружены: `models/exercise_classifier.pth`, `models/yolov8n-pose.pt`
- Проверить логи в `logs/pipeline.log` (если существует)

## Сводка критериев качества

### ✅ Хороший результат:
- `status` = "ok"
- `confidence` ≥ 80%
- `exercise` ∈ ["pushup", "pullup"]
- `technique_issues` = [] (или содержит исправимые проблемы)
- `metrics` содержит разумные углы (не NaN, не 0)

### ⚠️ Подозрительный результат:
- `confidence` < 60%
- `metrics` содержат значения вроде 0° или 180°
- Слишком много `technique_issues` одновременно

### ❌ Ошибка:
- `status` = "error"
- `error` содержит описание проблемы
- Все остальные поля = null/[]

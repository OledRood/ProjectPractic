# ProjectPractic

## Описание
Проект "ProjectPractic" направлен на оценку позы человека и анализ выполнения физических упражнений. Используется оценка скелетной модели человека.

## Технологии
Проект реализован на Python.

## Установка
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/OledRood/ProjectPractic.git
   ```
2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование
1. Запустите основной скрипт:
   ```bash
   python main.py
   ```
2. Следуйте инструкциям на экране.
3. Если вы используете macOS, можно воспользоваться скриптом `start_mac.sh`, выполнив следующую команду:
   ```bash
   ./start_mac.sh
   ```
   - Выберите один из доступных режимов в интерактивном меню:
     - 1: Запустить всё (backend + frontend)
     - 2: Запустить только backend
     - 3: Пересобрать и запустить проект
     - 4: Остановить все контейнеры
     - 5: Просмотреть логи
     - 6: Проверить статус контейнеров

## Особенности
- Поддержка анализа различных физических упражнений
- Высокая точность оценки поз
